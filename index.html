Projects

Gogomon

A mobile tamagotchi app developed with .Net Maui. Using a stepcounter to interact with your virtual pet on both Android and wearOS devices. The app works with both JWT authentication as well as Google sign-in integration and includes features such as adding friends, a streak system, leaderboards and an in game currency/shop system.

TheaterMaster

A restful API-based theater management system with a blazor frontend. JWT authentication and role-based access control implemented for secure user management.

Cs2Tracker

A real-time Counter-Strike 2 match reporting app built with Blazor Server and SignalR, broadcasting live scores and events from a reporter to viewer clients.

Includes a full domain model for matches, rounds and events, plus a console showcase of newer C# 12 features like primary constructors and collection expressions.

CookBookNook

A personal cookbook app where every user manages their own dishes and recipes, built with a .NET 8 API orchestrated via .NET Aspire and a Blazor frontend.

Uses ASP.NET Identity with JWT authentication, EF Core with SQL Server, and Redis-backed caching for fast recipe lookups.
